# ScienceSpark 🔬✨

An AI-powered learning companion designed specifically for NSW Science students in Years 7-10. This application is fully aligned with the NSW Science 7-10 (2023) NESA syllabus, providing a personalized and engaging learning experience.

## Overview

ScienceSpark aims to revolutionize science education by offering intelligent tools that adapt to individual student needs, making complex scientific concepts accessible and enjoyable.

## Features

-   **AI Tutor**
    -   Engage in interactive, chat-based learning with a knowledgeable AI science teacher.
    -   Receive personalized explanations, relevant Australian examples, and content directly aligned with the curriculum.
-   **Quiz Generator**
    -   Generate dynamic, AI-powered quizzes covering all Stage 4 and Stage 5 topics.
    -   Get instant feedback on answers and detailed explanations to deepen understanding.
-   **Resource Recommender**
    -   Access a curated collection of high-quality, free learning resources.
    -   Includes educational YouTube videos, interactive simulations (from platforms like PhET and LabXchange), free online textbooks (e.g., OpenStax, OER Commons), and practical hands-on activities.
-   **Progress Tracking**
    -   Monitor and visualize learning progress across all NSW Science NESA syllabus outcomes.
    -   Identify strengths and areas for improvement with intuitive dashboards.

## Curriculum Coverage

ScienceSpark covers the entire NSW Science 7-10 (2023) NESA syllabus, including:

### Stage 4 (Years 7-8)
-   Observing the Universe
-   Forces
-   Cells and Classification
-   Solutions and Mixtures
-   Living Systems
-   Periodic Table & Atomic Structure
-   Change
-   Data Science 1

### Stage 5 (Years 9-10)
-   Energy
-   Disease
-   Materials
-   Environmental Sustainability
-   Genetics & Evolutionary Change
-   Reactions
-   Waves and Motion
-   Data Science 2

## Australian-Focused Learning

All content is developed with an Australian context, incorporating Australian examples, Aboriginal and Torres Strait Islander perspectives, and real-world connections relevant to NSW students.

## Tech Stack

-   **Frontend**: React, TypeScript, Tailwind CSS, Framer Motion
-   **Backend**: Base44 (Backend-as-a-Service providing authentication, database management, and robust AI integrations)
-   **AI Integration**: Utilizes Large Language Models (LLMs) for intelligent tutoring, content generation, and resource curation.
-   **UI Components**: Shadcn/ui, Lucide React (for icons)

## How It Was Made

ScienceSpark was developed using the Base44 platform, which provided the foundational backend infrastructure. The frontend is built with modern web technologies: React and TypeScript for dynamic user interfaces, and Tailwind CSS for efficient and responsive styling, complemented by Shadcn/ui components for a polished look. AI integrations are powered by Base44's built-in LLM capabilities, enabling the intelligent features of the AI Tutor, Quiz Generator, and Resource Recommender. The development process emphasized modularity and iterative refinement.
